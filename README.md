# unpatched

Tells you when software you run has a vulnerability you need to act on, and
what to do about it.

> This repository is being rewritten from CVEWatch (Go) into `unpatched`
> (Rust). See [PLAN.md](PLAN.md) for the design. The Go tool is frozen at the
> last 2.x release.
