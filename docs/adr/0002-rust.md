# 2. Rust, one binary

Date: 2026-11-23. Status: accepted.

## Context

The tool runs in GitHub Actions, on laptops, in Docker and as an MCP server.
It must start fast, install without a runtime, and have a core that is easy to
test without the network. The old tool was written in Go.

## Decision

Rust (edition 2024), as a Cargo workspace with one binary. The core crate
(`unpatched-core`) is pure: no network, no files, no clock. Sources, the
database, notifiers and the MCP server are separate crates that depend on the
core. HTTP uses `reqwest` with rustls (no OpenSSL), SQLite uses `rusqlite` with
the bundled library. The minimum supported Rust version (MSRV) is checked in CI.

## Consequences

- Static binaries for Linux (musl), macOS and Windows, built by `dist`.
- Version parsers and the matching rules get property tests and fuzz targets.
- Contributors need a Rust toolchain. `cargo xtask check` is the one command
  to run before a commit.
- The Go code is deleted. It stays reachable under the `v2-final` tag.
