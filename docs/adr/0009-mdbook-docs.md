# 9. Documentation with mdBook

Date: 2026-11-23. Status: accepted.

## Context

The first plan reused an Astro site from another project. That brings a Node
toolchain into a Rust repository, only to render Markdown.

## Decision

The guide lives in `docs/guide/` and is built with mdBook (`book.toml`) and
published to GitHub Pages by `pages.yml`. Pages that depend on the code (the
config reference, the catalog list, the rule ids) are generated by `xtask`, and
so is `llms.txt`. Architecture decisions stay in `docs/adr/`, in the
repository only.

## Consequences

- No Node, no lockfile, nothing extra to keep updated.
- Fewer layout options than a full site. A catalog browser or an accuracy
  chart would need a small script added to the book.
