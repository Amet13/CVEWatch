# unpatched-catalog

The product catalog of unpatched: product ids, the CPE, CNA and CISA KEV keys that find them in the data, and their version schemes. The data is generated from `catalog/*.yml` in the repository.

This crate is part of [unpatched](https://github.com/Amet13/unpatched), which tells you when software you run is affected by a vulnerability, and only then.
It is built for unpatched and its API can change between major versions.
