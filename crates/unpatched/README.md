# unpatched

The `unpatched` command line tool: it reads your stack (`unpatched.yml`), checks it against open vulnerability data and tells you only what needs action.

This is the main crate of [unpatched](https://github.com/Amet13/unpatched), which tells you when software you run is affected by a vulnerability, and only then.
Install it with `cargo install unpatched` or use a release binary.
