# Security Policy

## Supported Versions

CVEWatch follows a rolling support model for the latest release on the `main` branch.

| Version | Supported |
| ------- | --------- |
| Latest release | ✅ |
| Older releases | ❌ |

## Reporting a Vulnerability

Please do **not** open public issues for potential security vulnerabilities.

Report vulnerabilities privately by emailing the maintainer listed in the repository profile, and include:

- A clear description of the issue
- Impact assessment (what can be exploited and under which conditions)
- Reproduction steps or proof-of-concept
- Suggested mitigation if known

You can expect:

- Acknowledgment within 72 hours
- Initial triage and severity assessment
- Coordinated disclosure after a fix is available

## Disclosure Policy

- Security fixes are prepared and validated before public disclosure.
- Affected users are notified through a GitHub release note.
- Credit is given to reporters unless anonymity is requested.
